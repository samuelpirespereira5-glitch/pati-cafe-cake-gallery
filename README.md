# Pati Cafe Cake Gallery

Utilize TODAS as 7 fotografias que estou enviando como imagens principais do site da Pati Café Boutique.

IMPORTANTE:

Não ignore nenhuma das fotografias.

Não substitua minhas fotos por imagens genéricas.

Use as fotos dos bolos, cafés, sobremesas e vitrines nas seções correspondentes.

Crie uma galeria elegante com essas fotografias.

Use a foto do bolo de chocolate como destaque na página inicial.

Preserve a qualidade e as proporções das imagens.

Organize as fotografias de maneira profissional, valorizando os produtos reais da cafeteria.

Quero que o site represente visualmente a verdadeira Pati Café Boutique, utilizando as fotos reais enviadas. tem as fotos tbm pode fazer o site por favor
